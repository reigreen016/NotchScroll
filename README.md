# NotchScroll 0.3.3 — メニューバー内スクロール試作版

Apple Silicon / macOS 14以降向け。

## 起動

1. 旧版NotchScrollが動いている場合は、↔メニューから終了します。
2. このフォルダのNotchScroll.appを固定の場所に置いて開きます。
3. システム設定 → プライバシーとセキュリティ → アクセシビリティで許可します。許可済みでも反応しなければ再起動し、必要に応じて登録し直してください。
4. ノッチより右側のメニューバー上で2本指スクロールします。

青いメニューバーと左右の矢印を組み合わせたアプリアイコンを追加しました。標準メニューバーには同じモチーフの白黒アイコンが表示されます。

通知との重なりを避けるため、表示中のバーと名前表示のウィンドウ階層を引き上げました。通知がある環境での前後関係は実機で未検証です。

バーの左右の端を、高さの半分の角丸に変更しました。スクロール中のアイコンも丸い輪郭の内側で切り抜かれます。

## 操作

- 同じ位置・高さに重ねたバーのアイコンが左右に動きます。縦スクロールも横移動として扱います。
- 最初は一覧の右端を表示します。指の動きに合わせて左側の項目も探せます。
- アイコンにポインタを置くと、約0.15秒以内に、実際に表示されているバーの下端から6ポイント空けてアプリ名・項目名を表示します。
- クリックするとオーバーレイを閉じ、元の項目にクリック操作を要求します。
- 表示を維持する範囲は、バーの左右20ポイント・下側40ポイントまで広げています。その範囲を外して約1秒経つと標準表示に戻ります。その間に戻すと表示を維持します。右端の×や外側のクリックではすぐ閉じます。スクロール位置は保持します。
- バー右側の「終了」でアプリを終了できます。右端の×はバーを閉じるだけです。標準メニューバーのNotchScrollメニューからも終了できます。

## 本来のアイコン画像を使う（任意）

↔メニューの「表示中の元アイコンを取得…」を選びます。画面収録を許可したあと、必要なら再起動して再度選んでください。

表示中のメニューバー項目の画像を画面から切り出し、メモリ内に保持します。通信・画像のファイル保存は行いません。画面全体のキャプチャは切り出し処理後に破棄されます。

ノッチ裏の項目は撮影できないため、アプリのアイコンで表示します。初期状態ではすべてアプリのアイコンです。撮影したアイコンは静止画で、変化した場合は手動で再取得してください。

## 制約と確認状況

- 標準メニューバー自体は移動しません。同じ位置を覆う表示によって操作感を再現します。時計なども表示中は覆われる場合があります。
- 元のメニューはmacOS側の位置で開きます。スクロール後のアイコン直下に開くとは限りません。
- 項目の取得・操作は各アプリのアクセシビリティ対応に依存します。隠れた項目も含め、全項目の取得・操作は保証できません。
- 複数画面の項目はまとめて表示します。画像取得はポインタのある画面のみです。
- 自動的に隠れるメニューバー、フルスクリーン、画面配置変更時の動作は未検証です。
- 最初のスクロールは監視方式なので、元のメニューバーにも伝わる可能性があります。
- ビルド・ローカル署名の整合性を確認。実機の権限付与後のジェスチャー、画像取得、メニュー操作は未検証です。
- Developer ID署名・Appleの公証はありません。

## ビルド

Apple SiliconのMacとXcode Command Line Toolsが必要です。

```sh
./Scripts/build.sh
```

`build/NotchScroll.app` と `build/NotchScroll-0.3.3.zip` を生成します。アイコンもソースから生成し、アプリにローカル署名します。
